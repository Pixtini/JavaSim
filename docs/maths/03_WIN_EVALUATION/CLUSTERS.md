# Cluster evaluation

Define how connected symbol groups form wins and how their payouts are calculated..

**CLU-001 -** A cluster is formed by multiple symbols of the same denomination that are orthogonally adjacent to eachother or other like denominations symbols those symbols are orthogonally adjacent to.
**CLU-002 -** A valid cluster pays anywhere providing its in view.
**CLU-003 -** Multiple clusters of different denomination can award on the same screen, all wins are added to the total win.
**CLU-004 -** If a wild is involved, it does not connect two denominations to form one big cluster, they are still their own clusters.
**CLU-005 -** Only highest paying amount per cluster is paid.
**CLU-006 -** If a wild or wild cluster is involved, it will be involved in all clusters that it could count for.

# Examples

Example of CLU-006, the minimun cluster is 5 symbols, there exists a 2x2 sqaure of wilds, surrounded by indivdual simple symbols, there will be a whole multitude of payouts of each symbol denomination + the 4 wilds. All of these wins are added to total win as a result of CLU-003.
