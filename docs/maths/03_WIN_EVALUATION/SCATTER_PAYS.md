# Scatter payouts

Defines the rules around scatter pays

**SCA-001 -** Symbols pay anywhere on the screen based on the number of symbols visible.
**SCA-002 -** Multiple symbol awards can be triggered at once, all wins are added to the total win.
**SCA-003 -** Only the highest award for one symbol is triggered.


# Examples

Example of SCA-003, there are 11 T1 symbols in view, 8+ T1 awards 5x, 10+ T1 awards 10x, therefore 10x is awarded.
