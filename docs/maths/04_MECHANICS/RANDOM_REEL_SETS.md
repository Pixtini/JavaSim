# Random reel sets

Defines the rules around reelsets.

**RSE-001 -** Game config is made up multiple sets.
**RSE-002 -** Each set must be a valid.
**RSE-003 -** The set is selected by weights first.
**RSE-004 -** The spin is played out by using the selected set exclusivly.
**RSE-005 -** Sets usually have the exact same tables. Any tables that arnt valid are turned off via the mathematics.
