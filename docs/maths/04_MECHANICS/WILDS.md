# Wild symbols

Define wild substitution, wild variants, and any limits on their use.

**WIL-001 -** Wilds count for every simple symbol at the same time.
**WIL-002 -** Wilds may form their own wins if their payout if higher than another payout it would contribute too.
**WIL-003 -** Wins involving wilds are still counted as the simple symbol win, unless its a wild only win.
**WIL-004 -** Wilds can count for multiple wins at the same time.

# Examples

Example of WIL-003, WWA would be a 3oak A win, WWWA where 3oak Wild > 4oak A would be a 3oak Wild win.
