# Mystery reveals

Defines the rules around mystery symbols.

Expansion is sub feature of Transformations.

**MYS-001 -** A symbol is designated the mystery symbol.
**MYS-002 -** There will be a target set of symbols those mystery symbols can transform into. 
**MYS-003 -** All mystery symbols have to transform.
**MYS-004 -** It is decided by indivudal game rule if all transform to one target symbol or each transform on an individual basis.

# Examples

Example of feature. Mystery Symbol M exists on reels, upon landing all mystery symbols transform to one of the top symbols at uniform weight. Reels land, all M transform to T1. Wins are evaluated.
