# Respins

Defines the rules around Respins.

**RES-001 -** A respin may be partial or full, defined by game rules. 
**RES-002 -** A game rule will qualify when a respin is performed. 
**RES-003 -** No money is taken for a respin.
**RES-004 -** Wins are awarded before the respin takes place and added to current total.
**RES-005 -** During partial respin , only the designated reels will respin.
**RES-006 -** Reels are respun independent with replacement of the first spin, therefore the same reelstop is valid. 

# Examples

Example of Feature, there is a respin symbol which can land on reel 3. After wins are awarded all reels respin and wins are awarded again if any. This process repeats if theres another respin symbol on reel 3.
