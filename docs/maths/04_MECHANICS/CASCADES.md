# Cascades and refill

Defines the rules around Cascades.

**CAS-001 -** Eligble winning symbols are removed from the grid simulatanously after wins for that cascade are added to the current total win.
**CAS-002 -** Remaining symbols respect "gravity" and fall to their new locations.
**CAS-003 -** Symbols cannot pass through eachother as they fall.
**CAS-004 -** New symbols are taken where the reels left off. It is not a respin of some kind.
**CAS-005 -** Process repeats until there are no more valid wins.
**CAS-006 -** Freegames and mode transistions are completed after the cascades stop.


# Examples

Example of CAS-001, Simple Symbols wins would be removed, a free game triggering scatter amount would remain.

Example of CAS-002/CAS-003/CAS-004, Say a reel is ABCD and C is removed for a valid win, then the reel before the further drops would be Blank-ABD. Then if A was reelstop X, Blank would be replaced by reelstop X-1 and so on.
