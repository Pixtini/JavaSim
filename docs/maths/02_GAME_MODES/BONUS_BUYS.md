# Bonus Buy

**BON-001 -** Bonus Buy is an adapation of config to force a free game entry.
**BON-002 -** Usually there will not be a engine change to require Bonus Buy functionality. Nor a specific PAR setting outside set selection and symbol insertion. 
**BON-003 -** There will be config in PAR for Bonus Buys own reels , insertiont tables.
**BON-004 -** Bonus buys have a cost associated with them , normally around 100x of base stake.
**BON-005 -** Wins are still awarded by base stake.
