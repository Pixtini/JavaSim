# Basegame

Define basegame.

**BAS-001 -** Every buy option/bet contains a basegame spin
**BAS-002 -** Base game will have its own config and weights.
**BAS-003 -** Base game is usually one spin, unless the game has a respin mechanic.
**BAS-004 -** The game round will end after the spin concludes unless there is a freegame trigger.
**BAS-005 -** On round end in basegame balance is ammneded with the total basegame win.
**BAS-006 -** Basegame are always independant from one another.
**BAS-007 -** Basegame must fully conclude before Freegames are started.
**BAS-008 -** On spin end if there is a freegame , total basegame win is kept on win meter until freegames are finished.
