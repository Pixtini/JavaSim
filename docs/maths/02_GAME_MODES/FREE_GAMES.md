# Freegame

Define free spins.

**FRE-001 -** Freegames are triggered from the basegame and happen after basegame concludes.
**FRE-002 -** Freegames are made up of X spins. 
**FRE-003 -** There may be persistence across spins. Including sticky symbols or a global multiplier. 
**FRE-004 -** It may be possible to add more spins through a retrigger, in this case the spins awarded are added to the entitlement counter.
**FRE-005 -** Wins from each spin are ammended to the win meter.
**FRE-006 -** Balance is updated once on round end with the win meter amount.
**FRE-007 -** Besides persistent features, each free game spin is an independent event.
**FRE-008 -** If win cap is exceeded during a spin , freegame ends.
