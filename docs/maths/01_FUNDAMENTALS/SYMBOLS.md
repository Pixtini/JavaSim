# Symbols and properties

Define symbol types, properties, roles, and allowed changes.

**SYM-001 -** A symbol is defined by a symbol ID which is an integer.
**SYM-002 -** Visualy the player will see an icon on the grid.
**SYM-003 -** A symbol will have a type or many types.
**SYM-004 -** A symbol may or may not have its own payout.
**SYM-005 -** Only one symbol can be in a grid position unless specified otherwise.
**SYM-006 -** A SIMPLE symbol usually will only be used to give a payout with regards to its quantity and according to WIN_EVALUATION.
**SYM-007 -** A WILD symbol will count for every simple symbol at the same time, see WILDS.md for more.
**SYM-008 -** A SCATTER symbol will have an effect for a certain count regardless of where they are on the screen. This is usually reserved for the free games entry symbol. 
**SYM-009 -** Symbols act as the main driver for feature activation and activity on the screen.
**SYM-010 -** Simple Symbols are usually placed via reels.
**SYM-011 -** Non-simple symbols are usually placed via insertion tables.
**SYM-012 -** There are usually placement rules given per symbol.

# Examples

Example of SYM-003, A symbol may both be WILD and SCATTER awarding lines wins when involved in a line and award free games when there are X or more on the screen.

Example of SYM-011/SYM-012, A WILD symbol may be placed using an insertion table, it may have the rule that it cannot replace a SCATTER symbol on the grid.
