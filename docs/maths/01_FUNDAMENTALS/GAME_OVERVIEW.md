# Game Overview

A slot game utilises a state machine as a medium to gamble. Regardless of any features the following will be true for all slots of any kind.

**GOV-001 -** The game will feature many starting outcomes as a result of its mathematical model.
**GOV-002 -** Initial state will be dependant on reelsets and/or weight insertion tables.
**GOV-003 -** Final state will be dependant on a ruleset given by a game design document and Initial State.
**GOV-004 -** Each paid round is an independant event. See RNG.md for more.
**GOV-005 -** Each game contains a grid of some size and some shape. See GRID.md for more.
**GOV-006 -** Each game will contain multiple symbols. See SYMBOLS.md for more.
**GOV-007 -** Payouts will be defined by a win evaluation method. See 03_WIN_EVALUATION for more.
**GOV-008 -** Game rules and implementations differ from game to game and can be changed and adapted for balancing requirements.
