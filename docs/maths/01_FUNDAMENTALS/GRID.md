# Grid

Define grid positions, visible symbols, and changes to the grid.

**GRI-001 -** The grid is visible to the player.
**GRI-002 -** The grid normally consistents of X reels , with Y visible stops at a time.
**GRI-003 -** As default the grid is rectangular. 
**GRI-004 -** The grid may differ from game to game, including hexagonal positions , offset rows or varying heights, when this differs it will be explicitly covered in the GDD.
**GRI-005 -** Symbol triggered Features must be visible on the grid to be considered.
**GRI-006 -** (n,m) refers to a symbols position on the grid. With (0,0) being the top left most corner and (X,Y) being the bottom right most corner.
**GRI-007 -** The symbols shown on the grid are usually defined by reels.
**GRI-008 -** Symbols may be added to the grid using insertion tables.
