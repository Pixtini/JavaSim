# Ember Forge implementation

`config/` owns validated PAR data. `basegame/` selects ordinary/entry reels; `features/` evaluates the single Forge Freegame. `EmberForgeEvaluator` uses GMF line math; `EmberForgeSession` handles complete rounds, Heat lifetime, cap and replay. `model/` preserves typed screen/line details. See the workspace README and implementation handoff for launch and validation instructions.
