# Ember Forge checks

`EmberForgeGameTests` checks configuration, exact entry tickets/screens, Heat, maximum/lower caps, replay, display adaptation, accounting and reproducibility. `EmberForgeMathAudit` independently enumerates small reel products and applies the finite-state Heat recurrence. Optional `EmberForgePrototypeCheck` opens actual desktop windows to verify mode charging, presentation and settlement. Commands and retained evidence are in the workspace README and validation report.
